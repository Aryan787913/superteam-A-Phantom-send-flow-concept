## Frames and Captures

Press F to create mobile frames at **390 × 844** and desktop frames at **1440 × 900**. Name frames by state and viewport, such as `After / Review / Mobile`. Use consistent margins and readable captions; avoid shrinking an entire long page until text is illegible.

Place image captures with Figma's Place Image command, preserve aspect ratio, and crop only with a visible explanation. Before mode must use the seven actual JPEGs in the project root, not a `/before` folder and not a recreated interface. No visual inspection of those JPEGs was possible during this documentation work. Inspect them manually before labeling particular UI details; identify observations as user-reported until verified.

Use the generated `captures/` PNGs for After states. Cover funded home, empty onboarding home, token, recipient, warning, amount, review, failure, success, and save, using `capture-list.md`. Do not label an illustrative design as a product screenshot. Desktop captures contain the implemented 1120 x 820 two-column wallet within a 1440 x 900 canvas. Lead the presentation with the warning hero, especially its side-by-side address fingerprints and differing chunks.

## Numbered Callouts

Use small numbered circles outside important controls, connected with short lines. Pair each number with one concrete explanation beside the capture, not over the content. Suggested annotations:

1. INR provides a familiar amount reference; SOL remains visible.
2. Recipient verification asks for an independent check, not trust in a familiar-looking fragment.
3. Review separates transfer amount, example fee, and destination.

Restart numbering per comparison and use the same number for the same concept across Before and After only when genuinely comparable. Do not invent missing Before screens to complete a comparison.

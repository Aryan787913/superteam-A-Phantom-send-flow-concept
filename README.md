## Validation

An expert cognitive walkthrough used a first-time UPI sender persona on mobile and desktop. No participant testing was conducted. Sending ₹50 to Rahul takes six taps when the optional full-address review is included. The walkthrough checked warning reachability, hold feedback, balance arithmetic and saved-recipient receipts. Next: moderated tests with five first-time senders.

## Run Locally

Run `python -m http.server 8000` from this folder, then open http://localhost:8000. No build step is required.

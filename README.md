## Run Locally

Run `python -m http.server 8000` from this folder, then open http://localhost:8000. No build step is required.

## GitHub Pages

In repository Settings > Pages, deploy from branch `main`, folder `/ (root)`. The expected URL for this repository is https://aryan787913.github.io/superteam-A-Phantom-send-flow-concept/ once Pages is enabled. All local assets use relative paths, including under a `/first-500-solana/` project path.
